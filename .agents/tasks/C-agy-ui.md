Read AGENTS.md, docs/CONCEPT.md (Schermen, Visuele richting, Dots en animaties), docs/ARCHITECTURE.md (Visual tokens) and lib/core/*.dart (AppState, SyncEngine, models). Use only AppState/SyncEngine public APIs (Provider).

Build
- lib/ui/theme/: tokens (paper #F5F0E8, ink #1A1A1A, coral #FF4F81, lime #CCFF00, blue #2979FF, amber #FFA41F; dark: bg #121212, surface #1E1E1E, text paper), ThemeData light+dark, fonts ArchivoBlack (headings) + SpaceGrotesk (body), subtle noise overlay painter (static, cheap).
- lib/ui/widgets/: BrutalCard / BrutalButton (radius 18, 2px border, hard offset shadow 4,4, press = shadow collapses in 120ms), StatusBar (dots + Dutch status text from statusLabel(), always text next to color), ItemCard (title, type icon+label, origin "van MacBook", sync state chip, progress bar for files), EmptyState.
- lib/ui/dots/: `DotSphere` CustomPainter that fakes a soft 3D sphere (radial gradients: base color, key light highlight top-left, rim light, soft contact shadow below). `DotsStage` widget animating per ConnectionStatus exactly per CONCEPT: unpaired one calm dot; searching two dots drifting in a small Lissajous pattern; pairing pull together; connected merge into a composition with a short bounce; syncing a small dot travels between them; offline dots further apart; failed animation stops. Also one-shot `sendPulse()` (small dot travels A→B) and `receivePulse()` (receiving dot pulses), triggered from SyncEngine.events. Interactions 200–500ms, ambient loops subtle and paused when app inactive (TickerMode / lifecycle) or settings.reducedMotion → simple fades only. Must hit 60fps; no shader packages, no 3D libs.
